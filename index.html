④ 持ち帰る：自分のアカウントへ

今日は「自分のURLが出るところまで」でOK。STEP 3 は事後課題でも大丈夫です。

  1. GitHubにコピーする
    下のボタンで、このサイトのコードを自分のGitHubにコピーします（右上の Use this template → Create a new repository）。
    GitHubでコピーを作る
  2. Vercelで公開する
    Vercelで Add New → Project を開き、いま作ったリポジトリの Import → Deploy。1分ほどで https://〇〇.vercel.app が出ます。
    Vercelを開く
  3. 自分のSupabaseにつなぐ（事後課題でOK）
    ① Supabaseで新しいプロジェクトを作る → ② SQL Editor に下のSQLを貼って Run → ③ Project Settings → API Keys の URL と publishable key を、GitHubの config.js に書き換えて保存（Vercelが自動で更新）。
    SQLを見る

    config.js に書いてよいのは publishable key（公開キー）だけ。secret key（秘密キー）は絶対に書かないでください。GitHubは誰でも見られます。

教育現場の5つのルール

  1. 本物の生徒情報・個人情報は入れない（練習はダミーデータで）
  2. 鍵は環境変数に置き、GitHubには上げない
  3. RLSは必ずON、AIに渡す権限は最小限に
  4. 公開URLは誰でも見られる前提で、公開範囲と投稿の確認を決める
  5. AIの出力（コード・分析結果）は、必ず人が確認する

このサイトのRLS（行レベルセキュリティ）

読む：誰でも（非表示にした口コミは除く）

書く：誰でも。ただし文字数・★1〜5・場所や季節の選択肢に制限

直す・消す：管理者だけ（ポリシーなし＝禁止）
